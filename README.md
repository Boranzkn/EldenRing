# Soulslike Gameplay Prototype (WIP)

## Overview

This is a **gameplay prototype project** inspired by *Elden Ring* and *Dark Souls*, developed in **Unity** with **C#**.  
The purpose of this project is not to create a full game, but to **study and replicate the core mechanics** of Soulslike games, including **combat systems, animations, environmental interactions, and multiplayer features**.

This is a **work in progress** and serves as a personal learning journey to deepen my knowledge of **game development, networking, and technical art integration**.

---

## Features (Planned & In Progress)

- Third-person character controller  
- Basic attack, block, and dodge mechanics  
- Animation system integration (Blend Trees, Animation Events)  
- Enemy AI 
- Combat hit detection and damage calculation  
- Multiplayer combat using **Unity Netcode for GameObjects**  
- Environment design & level building
- Graphics pipeline exploration (shaders, lighting, post-processing)  
- Optimization and performance tuning  

---

## Technologies Used

- **Unity Engine (URP)**  
- **C#**  
- **Unity Netcode for GameObjects**  
- **Git / GitHub** for version control  

---

## Goals

- Study and replicate **Soulslike mechanics** in a technical context  
- Learn **networked multiplayer implementation** in Unity  
- Explore **game feel**, graphics, and environment design  
- Practice **optimization** and project scaling in Unity
